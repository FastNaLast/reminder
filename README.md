# Напоминание

Маленькое Android-приложение для задач, которые нужно делать **раз в месяц**.

Например: «15 числа оплатить интернет», «1 числа снять показания счётчиков».

- Уведомление приходит в выбранный день и время.
- В уведомлении две кнопки: **Готово** и **Через час**.
- Переживает перезагрузку телефона.
- Если дня нет в месяце (31 февраля) — сработает в последний день.
- Без интернета, без рекламы, без аккаунтов. Данные только на телефоне.

## Где лежит проект

Файлы физически находятся здесь:

```
C:\Users\1DAM\Desktop\ПАПКА РАБОТА ПИТОН\M9L2
```

Но Android-сборка **не умеет работать с кириллицей в пути**. Поэтому создана
ссылка (junction) с латинским путём:

```
C:\Projects\MonthlyReminder  ->  M9L2
```

Это та же самая папка, просто второе имя. Все команды сборки запускаются по
латинскому пути.

> Если папку `M9L2` когда-нибудь переместить или переименовать, ссылка сломается.
> Починить одной командой в PowerShell:
>
> ```powershell
> cmd /c mklink /J C:\Projects\MonthlyReminder "C:\Users\1DAM\Desktop\ПАПКА РАБОТА ПИТОН\M9L2"
> ```

В VS Code лучше открывать папку `C:\Projects\MonthlyReminder` —
> тогда все задачи работают из коробки.

## Установка на телефон

### Способ 1 — по кабелю (быстрее всего)

1. На телефоне: `Настройки → О телефоне → Номер сборки` — нажать 7 раз
   (включится режим разработчика).
2. `Настройки → Система → Для разработчиков → Отладка по USB` — включить.
3. Подключить кабель, на телефоне разрешить отладку.
4. В VS Code выполнить задачу **«Установить на телефон (adb)»** или:

```powershell
C:\dev\android-sdk\platform-tools\adb.exe install -r C:\Projects\MonthlyReminder\app\build\outputs\apk\debug\app-debug.apk
```

### Способ 2 — файлом

1. Перекинуть `app-debug.apk` на телефон (Telegram «Избранное», облако, кабель).
2. Открыть файл, разрешить установку из этого источника.
3. Установить.

## После установки: выдать разрешения

Приложение само попросит уведомления. Остальное — в меню **«Разрешения»**
(три точки в правом верхнем углу).

### Poco M6 Pro (HyperOS)

1. `Настройки → Приложения → Напоминание → Уведомления` — включить.
2. `Настройки → Приложения → Напоминание → Батарея → Без ограничений`.
3. `Настройки → Приложения → Напоминание → Автозапуск` — включить.
4. В списке недавних приложений: зажать карточку → замок (защита от очистки).

### Samsung S24 Ultra (One UI)

1. `Настройки → Приложения → Напоминание → Уведомления` — включить.
2. `Настройки → Приложения → Напоминание → Батарея → Не ограничивать`.
3. `Настройки → Обслуживание устройства → Батарея → Спящие приложения` —
   убедиться, что приложения там нет.
4. `Настройки → Приложения → Напоминание → Будильники и напоминания` — разрешить.

Без этих шагов HyperOS и One UI могут «усыпить» приложение, и напоминание опоздает.

## Сборка в облаке (GitHub Actions)

Файл `.github/workflows/build.yml` собирает APK при каждом `git push` в `main`.

1. Создать пустой репозиторий на GitHub (без README).
2. В папке проекта:

```powershell
cd C:\Projects\MonthlyReminder
git init
git add .
git commit -m "Monthly reminder app"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПО.git
git push -u origin main
```

3. На GitHub: вкладка **Actions** → последняя сборка → **Artifacts** →
   `monthly-reminder-apk`.
4. Артефакт можно скачать прямо с телефона и установить.

Ключ подписи лежит в `keystore/debug.keystore` и **закоммичен специально**:
локальная и облачная сборки дают одинаковую подпись, поэтому приложение
обновляется, а не требует удаления. Это ключ для личного использования,
не для Google Play.

## Структура

```
app/src/main/java/ru/monthly/reminder/
  MainActivity.kt                экран списка, диалоги задачи и разрешений
  Task.kt                        модель задачи
  TaskStore.kt                   хранение (SharedPreferences + JSON)
  AlarmScheduler.kt              расчёт даты и постановка будильника
  ReminderReceiver.kt            будильник -> уведомление -> следующий месяц
  NotificationActionReceiver.kt  кнопки «Готово» / «Через час»
  BootReceiver.kt                восстановление будильников после перезагрузки
  Notifications.kt               канал и текст уведомления
  TaskAdapter.kt                 список

app/src/test/java/ru/monthly/reminder/
  AlarmSchedulerTest.kt          6 тестов на расчёт даты
```

Где что менять:

- тексты интерфейса и уведомлений — `app/src/main/res/values/strings.xml`;
- цвет — `app/src/main/res/values/colors.xml` (`brand`);
- задержка «Через час» — `NotificationActionReceiver.kt` (`minutes = 60`).

## Ограничения

- Точность ±несколько минут: Android не гарантирует секунду в секунду.
- «31 число» в коротких месяцах означает последний день месяца.
- Один месяц = один будильник; история выполнений не хранится.
